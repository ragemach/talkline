# مسیر پیشنهادی TalkLine Studio

بررسی: ۱۷ نوامبر ۲۰۲۶. این سند تصمیم توسعه است، نه گزارش تکمیل محصول.
مالک تأیید کرد: جلسهٔ خودش، حدود هفته‌ای یک بار؛ تعداد و ترتیب اسلایدها متناسب
با نوع جلسه و نمونهٔ همان جلسه باشد.

## انتخاب اصلی

Python 3.14، Ollama و رابط فعلی Streamlit حفظ شوند. بازنویسی رابط فعلاً کمکی به
ساخت خروجی کامل نمی‌کند. qwen3:8b نصب‌شده نقطهٔ شروع است؛ زمان و کیفیت تولید یک
جلسهٔ کامل هنوز باید اندازه‌گیری شود. تولید محلی به API پولی، سرور اجاره‌ای یا
حساب آنلاین نیاز ندارد. هزینهٔ Codex برای توسعه از اجرای برنامه جداست.
Streamlit روی همین رایانه اجرا می‌شود و رابط را در مرورگر نشان می‌دهد؛ نصاب و
پنجرهٔ مستقل بعد از پایداری خروجی‌ها بررسی شوند.
[معماری Streamlit](https://docs.streamlit.io/develop/concepts/architecture/architecture)

## ساختار محتوا

گام بعدی SessionPlan نسخهٔ ۲ است: موضوع، کانسپت، اطلاعات تأییدشدهٔ رویداد،
قالب، Toolkit سطح‌بندی‌شده، فعالیت‌ها، games[]، دعوت‌نامه، بازبینی و لینک‌ها.
این قرارداد هنوز پیاده‌سازی نشده است. قرارداد فعلی game تکی دارد و برای محصول
نهایی کافی نیست. هر جلسه یک یا دو بازی و Game Night دقیقاً دو بازی دارد.
قرارداد هر مکانیک جدا باشد؛ Taboo کلمات ممنوع دارد و Problem Solver مسئله و
چالش. همهٔ بازی‌ها نباید به انتخاب A/B تبدیل شوند.

ابتدا فعالیت واقعی ساخته شود، سپس پاورپوینت و دعوت‌نامه همان را معرفی کنند.
تعداد اسلایدها از نمونهٔ هر کانسپت پیروی کند؛ ۲۳ قانون عمومی نیست. متن در شکل‌های
قابل‌ویرایش اصلی جایگزین شود. اگر Toolkit جا نشد، تعداد مطالب صفحه کم شود یا
همان صفحهٔ تأییدشده تکثیر شود؛ فونت کوچک نشود. گرم‌آپ‌ها ساده و مؤدبانه، واژگان
و عبارت‌ها دارای جملهٔ کاربردی و گرامر دارای توضیح و مثال باشند. یادداشت مدرس
در notes بماند.
[notes در python-pptx](https://python-pptx.readthedocs.io/en/latest/user/notes.html)

## تولید و بازیابی

تولید در بخش‌های کوچک، مثلاً پنج کارت، با JSON Schema، بررسی تعداد و تکرار و
تلاش مجدد محدود انجام شود. خروجی ساختاریافتهٔ Ollama، درستی محتوا و CEFR را
تضمین نمی‌کند. نقد محلی کمکی است؛ پیش‌نمایش و ویرایش انسانی باقی بماند.
[خروجی ساختاریافتهٔ Ollama](https://docs.ollama.com/capabilities/structured-outputs)

مراحل در پوشهٔ هر جلسه ذخیره شوند؛ تغییر هر بخش، خروجی وابسته را قدیمی کند.
روی GPU شش‌گیگابایتی فعلی درخواست‌های مدل ترتیبی باشند. ابتدا JSON محلی کافی
است؛ SQLite در صورت نیاز به تاریخچه، بدون سرویس اضافه. برای این منابع محدود
فعلاً vector database لازم نیست. منطق تولید و خروجی از UI جدا بماند؛ worker
مستقیماً API رابط Streamlit را صدا نزند.
[محدودیت threading](https://docs.streamlit.io/develop/concepts/design/multithreading)

## خروجی و انتشار

تصمیم نهایی مالک در همین روز: میزبان هدف Vercel Free است و Netlify انتخاب
نشده است. خروجی یک آرشیو استاتیک با مسیر ثابت هر جلسه باشد. خرید طرح پولی یا
فعال‌کردن Pro trial مجاز نیست. اتصال حساب و انتشار هنوز تأیید نشده است؛ ابزار
Vercel MCP در جلسهٔ فعلی موجود نیست. موفقیت فنی انتشار، تأیید شرایط استفادهٔ
تجاری نیست؛ مالک تجاری‌بودن رویدادها را تأیید کرده است.
[طرح رایگان](https://vercel.com/docs/plans/hobby)،
[شرایط استفاده](https://vercel.com/legal/terms)

بازی‌ها HTML مستقل با CSS/JS و دادهٔ داخلی باشند؛ بدون API، CDN یا کلید. همان
فایل آفلاین و آنلاین کار کند. PPTX قابل‌ویرایش خروجی اصلی است؛ LibreOffice برای
پیش‌نمایش محلی حفظ شود، اما تطابق پیکسلی تضمین نیست و تمام صفحات بررسی شوند.
[تبدیل LibreOffice](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html)

Canva مرحلهٔ اختیاری ورود PPTX باشد. پشتیبانی واردکردن PowerPoint تضمین حفظ همهٔ
فونت‌ها و لینک‌ها نیست؛ یک واردکردن واقعی باید آزمایش شود. links.txt نیز برای
کپی دستی لینک‌ها صادر شود.
[راهنمای Canva](https://www.canva.com/help/powerpoint-import/)

فایل‌های بازی برای Vercel به صورت HTML/CSS/JS مستقل آماده شوند؛ مسیرهایی مانند
 events/event-id/game-1.html ثابت بمانند و فایل جلسات قبلی حفظ شوند. GIF، PPTX
و ZIP حجیم روی سایت بازی قرار نگیرند. محدودیت‌های طرح رایگان بررسی شوند و نسخهٔ
آفلاین همیشه باقی بماند. هیچ لینک عمومی تا مشاهدهٔ انتشار موفق ساخته نشود.

ابتدا بستهٔ آفلاین کامل شود؛ پس از انتشار، آدرس‌های واقعی بررسی و نسخهٔ آنلاین
پاورپوینت نهایی شود. لینک منتشرنشده به عنوان آماده تحویل داده نشود. Rate Us
همان Google Form راهنمای مالک است. دعوت‌نامه فقط از کتابخانهٔ اصلی با نسبت
تصویر همان نمونه ساخته شود؛ طراحی جدید یا اجبار به عمودی ممنوع است.

## ترتیب اجرا

۱. قرارداد نسخهٔ ۲ و نقشهٔ قالب‌ها؛ ۲. محتوای کامل و پاورپوینت Spontaneous Talk؛
۳. اولین بازی واقعی و بستهٔ کامل آفلاین؛ ۴. دو بازی Game Night و بقیهٔ کانسپت‌ها؛
۵. Vercel و آزمون Canva؛ ۶. رابط بازیابی و نصب آسان ویندوز.

موفقیت با موضوع تازه، تمام صفحات رندرشده، ویرایش واقعی PPTX، محتوای سطح‌بندی‌شده،
بازی کامل آفلاین/آنلاین، لینک‌ها، GIF و ZIP استخراج‌شده سنجیده شود. اکنون تولید
محلی، دعوت‌نامهٔ پنج کانسپت و نمونهٔ پنج‌اسلایدی موجود است؛ پاورپوینت کامل، بازی
قابل‌اجرا و انتشار یکپارچه هنوز باقی مانده‌اند.
