# گزارش اولین مرحلهٔ اجرایی — ۱۷ نوامبر ۲۰۲۶

این پروژه نرم‌افزاری قابل استفادهٔ مجدد است؛ Codex فقط آن را توسعه می‌دهد. نسخهٔ فعلی همچنان نمونهٔ اولیه است.

## بررسی انجام‌شده

- راهنماها، کد و نمونه‌های HTML بررسی شدند؛ هر دو پاورپوینت مرجع اصلی ۲۳ اسلاید دارند. فایل‌های طراحی مرجع تغییر نکردند.
- Python واقعی: 3.14.5، ویندوز با build شمارهٔ 26300. شناسایی نام محصول از رجیستری عبارت قدیمی Windows 10 Enterprise را برگرداند؛ بنابراین نام دقیق نسخهٔ ویندوز از این روش تأیید نشد. دسترسی CIM نیز در محیط محدود بود.
- محیط خصوصی `.venv` ساخته شد. نصب بسته‌ها روی همین Python موفق بود و `pip check` خطای وابستگی ندارد؛ نصب Python 3.12 لازم نشد.
- بسته‌های دقیقِ آزمایش‌شده در `requirements-tested-win-py314.txt` ثبت شده‌اند. این فایل مخصوص تکرار محیط ویندوز/Python 3.14 است؛ نیازمندی عمومی همچنان `requirements.txt` است.
- دمو با موضوع متفاوت Unexpected Travel Adventures اجرا شد: ۵ اسلاید قابل ویرایش، ۲ کارت دادهٔ نمونه، GIF متحرک 1080×1920 با مدت ۶ ثانیه و تکرار دائمی، JSON و ZIP.
- تست رابط Streamlit دکمه‌های تولید محتوا و ساخت فایل را اجرا می‌کند و ZIP نهایی را باز و بررسی می‌کند.
- خود `START_WINDOWS.bat` در حالت آزمایشی بدون مرورگر اجرا شد؛ آدرس سلامت محلی پاسخ `ok` داد. فرایند آزمایشی پس از بررسی بسته شد.
- تصویر انتهایی دعوت‌نامه در اندازهٔ موبایل بازبینی شد. این بررسی جای ارزیابی بصری همهٔ موضوع‌ها و اسلایدها را نمی‌گیرد.

## مشکلات اصلاح‌شده

- درخواست ایمیل Streamlit در اولین اجرا مانع شروع خودکار بود؛ اکنون در تنظیمات پروژه خاموش است. آمار استفاده نیز خاموش است.
- محل و ساعت رویداد قدیمی دیگر پیش‌فرض رویداد جدید نیستند. دادهٔ نامعلوم در GIF با TO BE ANNOUNCED نمایش داده می‌شود؛ مقدار اصلی JSON خالی می‌ماند.
- دادهٔ خراب مدل، متن خالی، نوع اشتباه، عنوان تکراری و انتخاب‌های یکسان رد می‌شوند. این فقط اعتبارسنجی ساختاری است، نه داوری کیفیت معنایی یا سطح CEFR.
- پس از شکست تولید جدید، خروجی رویداد قبلی دیگر برای دانلود باقی نمی‌ماند.
- برش مخفی اطلاعات رویداد حذف شد؛ متن رویداد در دو خط جا می‌گیرد یا خطای قابل فهم می‌دهد. واژه‌های بسیار بلند شکسته می‌شوند. عنوان یا شعارِ جا‌نشدنی رد می‌شود.
- شمارهٔ کارت‌های نمونه اصلاح شد و یادداشت مجری به پنج اسلاید نمونه اضافه شد.

## اجرای ساده

۱. پوشهٔ داخلی `TalkLine_Studio_CODEX_HANDOFF` را باز کنید؛ همان پوشه‌ای که `app.py` دارد.

۲. روی `START_WINDOWS.bat` دوبار کلیک کنید. پنجرهٔ بازشده را تا پایان استفاده نبندید. اگر مرورگر باز نشد، آدرس http://127.0.0.1:8501 را در مرورگر وارد کنید.

۳. Demo را انتخاب کنید، موضوع را بنویسید و Generate prototype را بزنید؛ سپس Build PPTX + Full HD GIF را بزنید. تغییر اطلاعات رویداد نیاز به زدن دوبارهٔ Generate دارد.

۴. فایل ZIP را دانلود و استخراج کنید. نمونه‌های تولیدشدهٔ توسعه در `output/smoke-demo` نیز موجودند.

هیچ اقدام نصب دیگری برای دمو لازم نیست. مدل Ollama دانلود نشده و اجرای واقعی AI تأیید نشده است؛ نبود دستور `ollama` در PATH به‌تنهایی ثابت نمی‌کند که نرم‌افزار روی سیستم نصب نیست.

## تست دوباره برای توسعه

دستورها را در پوشهٔ داخلی پروژه اجرا کنید:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/smoke_demo.py
.\.venv\Scripts\python.exe scripts/check_windows_startup.py
```

بررسی لانچر نیاز دارد که برنامهٔ دیگری روی پورت 8501 باز نباشد. تست‌های معمول به مدل محلی یا API پولی نیاز ندارند. در محیط محدود Codex، نصب اینترنتی و تست سرور محلی نیازمند مجوز محیط بودند؛ این محدودیتِ محیط توسعه است.

## مرحلهٔ بعد و محدودیت‌ها

M0 انجام شده و اعتبارسنجی اولیهٔ قرارداد پروتوتایپ اضافه شده است. M1 کامل نیست: قرارداد دادهٔ محصول کامل، ذخیرهٔ تنظیمات، نقد معنایی محلی و بازتولید بخش‌ها باقی مانده‌اند. سپس M2 باید قالب واقعی ۲۳ اسلایدی را با حفظ طرح پیاده‌سازی کند.

بازی HTML قابل اجرا، محتوای ۲۰+۲۰ کارت، خروجی کامل ۲۳ اسلاید، کنترل کیفیت جامع، انیمیشن نهایی مطابق طراحی مرجع و نصب‌کننده هنوز پیاده‌سازی نشده‌اند. دمو محتوای ثابتِ نمونه دارد و برای هر موضوع محتوای خلاقانهٔ تازه نمی‌نویسد. نمایش بصری پاورپوینت در PowerPoint/LibreOffice در این مرحله تأیید نشده است؛ تست فعلی ساختار، متن قابل ویرایش، یادداشت و محدودهٔ شکل‌ها را بررسی می‌کند.
